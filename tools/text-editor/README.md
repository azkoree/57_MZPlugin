# 文本 json 编辑器（tools/text-editor）

为 **WSQ_MultiTextDatabase** 插件配套的可视化文本库编辑器。用于新建、编辑、保存、另存为
文本 json 文件（`en.json`、`db.json` 等），支持中文键名、任意嵌套深度、保存前自动备份。

技术栈：**Vite + Vue 3 前端 + Express 后端**（本地单机工具）。

---

## 快速开始

### 方式一：双击启动（推荐）

双击 `tools/text-editor/start.bat`，首次会自动安装依赖并打开浏览器
`http://localhost:5173`。之后每次双击直接使用。

关闭：直接关掉命令行窗口即可（Ctrl+C 亦可）。

### 方式二：手动命令

```bash
cd tools/text-editor
npm install        # 仅首次
npm run dev        # 开发模式，访问 http://localhost:5173
```

### 生产模式（可选）

```bash
npm run build
npm run start      # Express 直接托管 dist，访问 http://localhost:3001
```

## 功能说明

| 功能 | 说明 |
|------|------|
| 选择目录 | 点击文件栏顶部目录条，弹出「设置文本库目录」对话框：可直接**输入/粘贴路径**，或点「浏览…」用系统文件夹对话框选择；刷新页面会记住上次目录 |
| 文件管理 | 列出当前文本库目录下所有 `.json`；新建（空文件）、重命名、删除、刷新列表 |
| 编辑 | 左侧选文件 → 中间点分组 → 右侧显示该分组下所有键的**卡片列表**（每卡片约 4 行输入框，可批量编辑）；`Ctrl+S` 保存 |
| 复制引用 | 点击右侧卡片标题（`分组名.标题`）自动复制占位符 `${文件名, 分组名.标题}` 到剪贴板 |
| 换行格式 | 输入框内直接回车换行；顶栏可切换换行的保存格式：`<br>`（RMMZ 控制符）或 `\n`（字面转义），选择持久化；打开旧文件时 `<br>` / `\n` 会自动还原为多行显示 |
| 保存保障 | 保存前自动把旧文件备份为 `同名.json.bak`；采用「临时文件 + 原子替换」写入，中途崩溃不会损坏原文件；内容为 **UTF-8 无 BOM + Tab 缩进**，与现有库文件格式一致，插件可直接读取 |
| 另存为 | 输入新文件名，直接保存到当前文本库目录 |
| 未保存提示 | 顶栏与文件列表显示 `●`；切换文件 / 新建文件时弹出确认 |
| 文件管理细节 | 重命名文件时 `.bak` 一并迁移；删除文件时 `.bak` 一并清理 |

### 树操作（中间栏）

- 分组行：`▾` 展开/折叠（同时右侧显示该分组）；`＋` 在该分组下新增键；`✎` 重命名；`✕` 删除（有确认）
- 键行（字符串）：点击后右侧滚动定位到对应卡片；`✎` 重命名；`✕` 删除
- 顶部 `＋分组`：新增顶层分组
- 数字 / 布尔 / 数组等非字符串值：树中显示为只读（插件只引用字符串）

### 右侧卡片列表

- 当前分组下的每个键一张卡片，标题为 `分组名.键名`；**点击标题即复制**占位符 `${文件名, 分组名.键名}`
- 每卡片输入框约 4 行高，可上下拖拽拉伸；下方显示字数
- 点击中间树的键可快速滚动定位到对应卡片

> 注意：重命名 / 删除分组或键会改变引用路径（`${文件名, 分组.键}`），游戏内相应引用
> 将显示「缺失文本」，操作前请确认引用处无需同步修改。

## 引用语法速查（对应插件 WSQ_MultiTextDatabase）

```
${文件名, 分组.键}       例：${db, 用语.标题}
```

- 文件名：json 基名（不含 `.json`），须在插件参数「文本文件列表」中注册才能被加载
- 分组.键：用 `.` 表示的多级路径，支持中文

## 后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/status` | 当前工作根（绝对路径，可能为 null）与文件列表 |
| POST | `/api/pick-dir` | 弹出系统文件夹选择器，选定后设为工作根；取消返回 `{cancelled:true}` |
| GET | `/api/workdir` | 获取当前工作根 |
| POST | `/api/workdir` | 设置工作根 `{dir}`（绝对路径，须为已存在目录） |
| GET | `/api/files` | 工作根下 json 基名列表 |
| GET | `/api/file?name=x` | 读取文件（解析为对象） |
| POST | `/api/file` | 保存 `{name, data}`（备份 + 校验 + Tab 缩进） |
| POST | `/api/file/new` | 新建空文件 `{name}` |
| POST | `/api/file/rename` | 重命名 `{oldName, newName}` |
| DELETE | `/api/file?name=x` | 删除文件 |
| POST | `/api/save-as` | 另存为 `{name, data}`（保存到当前工作根） |

安全限制：文件名仅允许 `字母/数字/下划线/中文/连字符`；工作根为用户显式选定的目录，
所有读写只发生在其下；服务仅监听 `127.0.0.1`（本机）。

## 常见问题

- **打不开 / 报错**：确认 Node.js 已安装（v18+）；双击 `start.bat` 时注意命令行窗口不要提前关闭。
- **目录选择器没反应**：设置目录有两条路——① 直接输入路径（不依赖系统对话框，任何情况可用）；②「浏览…」系统对话框（依赖 Windows PowerShell + WinForms，被安全软件拦截时可能不显示，此时用路径输入即可）。
- **多标签页**：工作根是会话级状态（服务端内存），请同时只开一个标签页，否则可能互相覆盖。
- **保存后游戏里没变化**：在游戏中使用插件指令「刷新文本库 / 刷新文本文件」（开发期参数「允许热重载」需为 true），并确认该 json 在插件参数「文本文件列表」中注册。
