## 关于插件名称前缀

由于起初只是写给自己项目的插件，没打算对外发布，因此没有特别注意插件的取名，冒用了GF的名义非常抱歉

但是现在插件比较多了，而且若要修改，其他直接链接到插件的文章就需要重新修改链接，还要改插件内部引用自身的代码，比较麻烦，所以先不改了。如果真的很在意这个，可以自行修改为前缀**WSQ**（实在不清楚引用自身的代码什么意思的话，随便丢给一个网页ai都能告诉你怎么改）
